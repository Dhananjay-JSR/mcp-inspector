MCP Inspector

Connect to an MCP server, inspect its tools, and call them with your own arguments.

STDIO is not available in VS Code for the Web. Use the desktop app or Codespaces, or connect to a remote server over SSE or Streamable HTTP.

A script path, or a command already on your PATH such as npx.

The transport is detected automatically: Streamable HTTP first, SSE for /sse endpoints.

OAuth 2.0 authorization code flow with PKCE (RFC 6749). The inspector opens a browser only when the server advertises OAuth metadata; a plain 401 shows an authentication error instead.

Sent with every request, for example Authorization: Bearer <token>.

For servers with a private CA or mutual TLS. Paths are saved to settings; file contents stay on this machine.

The client certificate and key must be set together.
